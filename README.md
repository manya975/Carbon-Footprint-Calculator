# Carbon Footprint Calculator

## Overview  
This is a web page for estimating a user’s annual carbon dioxide (CO₂) emissions based on four inputs: electricity usage, petrol consumption, short-haul flights, and long-haul flights. 
## How to Use  
1. Enter your average monthly electricity usage (in kWh).  
2. Enter your weekly petrol usage (in litres).  
3. Enter your total distance of short flights in a year (in km).  
4. Enter your total distance of long flights in a year (in km).  
5. Click **Calculate My Footprint**.  
6. The result section will appear showing:  
   - Total annual CO₂ emissions (in tonnes)  
   - Breakdown: electricity, petrol, short flights, long flights  

## Tech Stack  
- HTML and CSS
- JavaScript for calculation and animations  
- Responsive design via CSS media query  

## How to Run  
1. Open `index.html` in your browser (no server setup required).  
2. Fill in the form, click the button, and view the results.
